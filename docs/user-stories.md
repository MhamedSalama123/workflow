# User stories

Format: *As a <role>, I want <goal> so that <benefit>.* The phase in brackets is when the story gets built.

## Employee
1. As an employee, I want to report a problem with a title, description and photo so that someone can fix it. [P1]
2. As an employee, I want to pick the affected asset (optional) so that the technician knows which machine is meant. [P1]
3. As an employee, I want to see a list of my tickets and their status so that I know what is happening. [P1]
4. As an employee, I want to comment on my ticket so that I can add details later. [P1]
5. As an employee, I want to scan a QR code on a machine so that I can report a problem quickly. [P2]
6. As an employee, I want to be notified when my ticket is resolved so that I don't have to keep checking. [P2]
7. As an employee, I want to ask the self-help chatbot first so that I can fix simple IT problems without waiting. [P4]

## Technician
8. As a technician, I want to see the work assigned to me, sorted by due date, so that I know what to do next. [P1]
9. As a technician, I want to change a ticket's status (start, waiting for parts, resolved) so that everyone sees progress. [P1]
10. As a technician, I want to use WorkFlow on my phone with large buttons so that I can work at the machine. [P2]
11. As a technician, I want to log time and parts per ticket so that repair costs are tracked. [P2]
12. As a technician, I want to tick off a maintenance checklist before closing a planned ticket so that no step is skipped. [P2]
13. As a technician, I want to see an asset's repair history so that I can spot repeating failures. [P3]
14. As a technician, I want a pre-filled asset review form so that I can justify a repair-or-replace recommendation quickly. [P3]

## Manager
15. As a manager, I want a ticket board grouped by status so that I see the whole backlog at a glance. [P1]
16. As a manager, I want to assign a ticket to a technician so that every problem has an owner. [P1]
17. As a manager, I want to manage assets and locations so that the asset register stays correct. [P1]
18. As a manager, I want to create maintenance plans with an interval and checklist so that tickets are created automatically. [P2]
19. As a manager, I want overdue tickets highlighted and to be notified so that SLAs are kept. [P2]
20. As a manager, I want to see MTTR, MTBF and SLA compliance so that I can judge how the team performs. [P3]
21. As a manager, I want to approve, reject or defer replacement requests so that budget decisions are documented. [P3]
22. As a manager, I want AI-suggested category and priority on new tickets so that triage is faster, while I still decide. [P4]

## Admin
23. As an admin, I want to invite users by email and give them a role so that only known people get access. [P1]
24. As an admin, I want to deactivate a user so that people who leave lose access but their history stays. [P1]
25. As an admin, I want an audit log of who changed what so that changes can be traced. [P2]
